Bem-vindo ao site da disciplina

Este site reúne os trabalhos desenvolvidos ao longo da disciplina de Interface Web. Cada trabalho explora um conjunto de tecnologias do desenvolvimento front-end.

Ao longo do semestre, novos trabalhos serão adicionados a este site. Cada página utiliza os mesmos componentes de cabeçalho, menu e rodapé, criados como Web Components reutilizáveis.
